# GoatQuest 1.0.0

For WoW Forever beta (Interface 16001).

- One compact guide viewer with the matching GoatQuest skin.
- Arrow or ground halo navigation, with movable controls.
- Class or custom accent colours shared by the viewer, arrow, halo and waypoint pins.
- Leveling, dungeon and profession guides.

Download `GoatQuest-1.0.0.zip` and extract it into `Interface/AddOns`. The archive
contains the `GoatQuest` folder. Fully restart the game after installation.
